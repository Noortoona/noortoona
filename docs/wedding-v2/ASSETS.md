# Wedding V2 — مصادر الأصول

## الخلفيات

أُنشئت الخلفيات الاثنتا عشرة أصلًا لهذا التحديث باستخدام توليد الصور، دون وجوه أو أشخاص، ودون شعارات أطراف أخرى أو صور مائية. لا تعتمد على روابط صور خارجية. جرى فحصها بصريًا وتصديرها إلى أصول محلية محسّنة.

لكل تصميم خمس نسخ في `assets/templates/wedding-v2/`:

| النسخة | الأبعاد | الاستخدام |
| --- | --- | --- |
| `slug.webp` | 1024 × 1536 | المعاينة الكبيرة والدعوة |
| `slug-mobile.webp` | 640 × 960 | الجوال |
| `slug-thumb.webp` | 320 × 480 | المعرض والتحميل الكسول |
| `slug.jpg` | 1024 × 1536 | بديل JPEG متوافق |
| `slug-thumb.jpg` | 320 × 480 | بديل المعرض وصورة Expo المضمّنة |

لا تحتوي الخلفيات على أسماء أو نص الدعوة. النصوص والمونوغرام عناصر حقيقية ينشئها محرّك العرض وتبقى قابلة للتحرير.

## الخطوط

الخطوط مستضافة محليًا بصيغة WOFF2. التراخيص الأصلية SIL Open Font License موجودة بجوارها. أُخذت ملفات المصدر من مستودع Google Fonts الرسمي، ثم ضُغطت إلى WOFF2 دون تغيير الحروف أو أسماء الخطوط.

- [Amiri](https://github.com/google/fonts/tree/main/ofl/amiri): `Amiri-Regular.ttf`، وملف `OFL.txt`.
- [Aref Ruqaa](https://github.com/google/fonts/tree/main/ofl/arefruqaa): Regular وBold، وملف `OFL.txt`.
- [Tajawal](https://github.com/google/fonts/tree/main/ofl/tajawal): Regular وMedium وBold، وملف `OFL.txt`.

يبقى شعار هلا من `assets/brand/` كما هو، ولم تُعدّل أصول الهوية الرسمية. الألوان المرجعية الحالية في المشروع: `#0A0D13`، `#11151D`، `#D3A447`، `#F0D08A`، `#FBF7EF`.

## المعاينات المصوّرة

ملفات `previews/*.jpg` و`preview-grid.jpg` صور من محرّك الدعوة نفسه، باستخدام أسماء وبيانات عرض اصطناعية. لإعادة إنتاجها:

```sh
npm ci
npm run build
npx playwright install chromium
node scripts/capture-wedding-previews.mjs
```

هذه ملفات توثيق فقط، ولا تدخل مجلد النشر العام `dist`.
